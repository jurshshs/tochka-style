# ТОЧКА СТИЛЯ — демонстрационный магазин

Next.js App Router, TypeScript, Tailwind CSS, Motion, Lucide. 32 реальных товара, 125 фотографий, 6 непустых категорий. Брендинг и оригинальный логотип магазина — «ТОЧКА СТИЛЯ».

## Запуск на Windows

1. Скачайте репозиторий и откройте папку проекта.
2. Запустите start.cmd двойным щелчком. Оставьте окно открытым.
3. Откройте http://localhost:3000. Для остановки — Ctrl+C в окне сервера.

Если сервер уже работает, просто откройте адрес. Скрипт использует production-сборку; если её нет — создаёт её. После изменений выполните pnpm build.

Для разработки: откройте PowerShell в storefront, выполните pnpm dev.
Для восстановления зависимостей: pnpm install --frozen-lockfile.
Альтернатива без pnpm: npm install, npm run build, npm start.
Требуется Node.js 22+; здесь установлен 24.20.0.

## Страницы

Главная /, каталог /catalog, категории /category/[slug], товары /product/[slug], корзина /cart, демо-оформление /checkout, информация /about, 404.
Поиск, фильтры категории/размера/верхней цены, сортировка, галереи с увеличением, выбор размера, количество, сохранение корзины в localStorage, боковая корзина, мобильное меню.
Checkout ничего не отправляет и не собирает персональные данные.

## Данные и фотографии

lib/catalog.ts — типизированный адаптер. data/catalog.json — копия источника. public/images — копии фотографий. data/editorial.json — 8 визуально отобранных hot picks. data/image-overrides.json — порядок изображений и замена оригиналами.
Исходник ../catalog-data не редактируется витриной. pnpm prepare:data копирует обновлённый каталог, не запускает Kufar.

Для замены фото подготовьте D:\Originals\product-001\01.jpg, 02.jpg и аналогичные папки стабильных ID. Выполните:

```powershell
node scripts/import-originals.mjs 'D:\Originals'
pnpm build
```

Скрипт копирует JPG/PNG/WebP/AVIF в public/originals и обновляет manifest. Товары без новых файлов сохраняют прежние фото. Названия и цены не меняются. Порядок файлов алфавитный, используйте ведущие нули. Для возврата исходной галереи удалите запись ID из manifest. Водяные знаки не удаляются.

## Проверки

pnpm check и pnpm build. При работающем сервере на порту 3000: node scripts/verify.mjs, node scripts/qa.mjs и node scripts/qa-branding.mjs. Они используют видимый Chrome и Playwright из соседнего парсера, не обращаются к Kufar. Итоговые отчёты: verification-report.json и branding-report.json; новые прогоны также пишут рабочие копии в work.

## Публикация Vercel

Пока не выполнена. Для загрузки локального проекта нужно авторизовать CLI на этом компьютере:

```powershell
cd tochka-style
npx vercel login
npx vercel
```

Выберите свой аккаунт и новый проект tochka-stilya-storefront. Framework: Next.js, root: текущая папка, build: pnpm build. После проверки preview: npx vercel --prod.
Не загружайте парсер, резервные копии или browser profile. Альтернатива: импорт этого Git-репозитория в Vercel; корневая папка проекта уже содержит приложение.

## Будущие интеграции

Сохраните модели Product, ProductVariant, Category, CartItem; замените локальный адаптер серверным repository. Клиент получает готовые данные и безопасные API. Наличие, актуальные цены и суммы проверяются сервером. CRM, авторизация, остатки и оплата добавляются отдельными серверными модулями. Сейчас они не подключены.

## Ограничения

Фото временные, с водяными знаками. Качество ограничено исходными объявлениями. Наличие требует уточнения. Даты поступления неизвестны; порядок каталога не выдаётся за хронологию. Корзина не учитывает доставку. Тесты покрывают основные сценарии, а не все сочетания фильтров и браузеров.
